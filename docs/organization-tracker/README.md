# Organization Tracker

Organization Tracker is a bounded Civic Radar module that converts archived
documents and extracted passages into an evidence-backed, time-aware model of
an organization's structure, positions, people, memberships, and reporting
relationships.

It does not fetch or archive sources independently in the MVP. It consumes
Civic Radar's existing document archive and parsing outputs, records proposed
organizational assertions, reconciles them against accepted state, and creates
human-reviewable change events.

The module is designed to support government agencies, companies, and other
organizations. The first deployment target is the City of San Buenaventura
(City of Ventura).

See [MVP-PRD.md](MVP-PRD.md) for product requirements, scope, data model,
Ventura sources, workflows, and acceptance criteria.
